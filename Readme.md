# 🎓 Faculty Website

> This project was created as part of a college assignment for **Shoolini University**.  
> It allows users to view faculty members by selecting their respective **departments or courses**.

---

## 🧠 About the Project

The Faculty Directory is a simple full-stack web application that showcases detailed information about professors, including their **names**, **departments**, **roles**, and **contact info**.  
Users can easily **filter faculty** based on selected **courses or departments**.
